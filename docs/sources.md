# Sources (searched 2026-10-04)

No full decompilation of Secret of Mana exists on GitHub. `gh search repos` for "secret of mana", "seiken densetsu 2" and "som disassembly 65816" returned only tools and clones.

## Documentation
- Data Crystal, Secret of Mana: https://datacrystal.tcrf.net/wiki/Secret_of_Mana
- ROM map: https://datacrystal.tcrf.net/wiki/Secret_of_Mana_(SNES)/ROM_map
- RAM map: https://datacrystal.tcrf.net/wiki/Secret_of_Mana_(SNES)/RAM_map
- Bank disassemblies index (banks 00-02 only, engine code, no monster AI): https://datacrystal.tcrf.net/wiki/Secret_Of_Mana_Bank_Disassemblies
- Older disassembly notes: http://www.darkwoodinc.com/~enker/banks.php
- SFC wiki (J version map): http://wiki.superfamicom.org/snes/show/Seiken+Densetsu+2

## Repos
- Moppu/SecretOfManaRandomizer (patches ROM data, may document tables): https://github.com/Moppu/SecretOfManaRandomizer
- MatthewCallis/Secret-of-Mana-Graphic-Decompressor: https://github.com/MatthewCallis/Secret-of-Mana-Graphic-Decompressor
